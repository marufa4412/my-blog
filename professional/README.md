# Professional Analytics & Research Portfolio

This folder contains Marufa Akter's professional portfolio, designed to complement the existing personal blog.

## Live URL

Once the changes are merged to `main` and GitHub Pages has redeployed:

https://marufa4412.github.io/my-blog/professional/

## Contents

- `index.html` — accessible landing page, background, research, experience and contact information
- `style.css` — responsive dark navy and teal design
- `app.js` — structured, filterable project collection and project-details dialog

## Editing

For a project update, change the corresponding object in `app.js`. For colors, spacing or responsive layout, edit `style.css`. This is a static site: it runs via Live Server or GitHub Pages and **does not require Node.js or Vite**.

## Evidence policy

Only publish public research pages and reports after checking:
- academic authorship and group-member consent
- university submission and copyright rules
- privacy, student IDs, private contact details and respondent-level data
- licensing and redistribution rights for notebooks and datasets
- forecasts vs. actual business outcomes
- academic coursework vs. peer-reviewed publications

This version intentionally avoids publishing private original documents and does not claim completed BI dashboards that have not been verified.

## Relationship to the original site

The original root blog and its research pages remain in place. The root navigation points to this portfolio at `/professional/`.
